# Unidad1_T1.3 — Búsqueda lineal y binaria

Proyecto académico en C# para practicar **búsqueda lineal y búsqueda binaria**.

## Contenido

La aplicación de Windows Forms incluye su lógica principal en `MainForm.cs` y organiza el material complementario en la carpeta `Analisis`.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con `Unidad1_T1.3.csproj`.

## Ejecución

Abre `Unidad1_T1.3.sln` en Visual Studio y ejecuta el proyecto.

## Propósito

Conocer y comparar métodos de búsqueda sobre colecciones de datos.
